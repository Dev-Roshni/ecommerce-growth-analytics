
# E-Commerce Growth, Profitability & Supply Chain Analytics

## Project Overview
An end-to-end e-commerce analytics project built to evaluate business performance, identify growth opportunities, and support data-driven decision-making using PostgreSQL, SQL, and Power BI.

## Key Analysis Areas
- Revenue and order trends
- Product category performance
- Order status analysis (Delivered, Returned, and RTO)
- Revenue contribution by acquisition channel
- Year-over-year business performance

- Microsoft Power BI
